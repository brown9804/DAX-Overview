# References and next steps

## Primary technical references

- [Microsoft DAX overview](https://learn.microsoft.com/en-us/dax/dax-overview):
  language concepts and calculation objects.
- [DAX function reference](https://learn.microsoft.com/en-us/dax/dax-function-reference):
  syntax, restrictions, and product applicability.
- [DAX queries](https://learn.microsoft.com/en-us/dax/dax-queries):
  DEFINE, EVALUATE, result tables, and ordering.
- [DAX query view](https://learn.microsoft.com/en-us/power-bi/transform-model/dax-query-view):
  query authoring and supported model-update actions.
- [Star-schema guidance](https://learn.microsoft.com/en-us/power-bi/guidance/star-schema).
- [Date-table guidance](https://learn.microsoft.com/en-us/power-bi/transform-model/desktop-date-tables).
- [Row-level security](https://learn.microsoft.com/en-us/fabric/security/service-admin-row-level-security).

Microsoft documentation is the primary reference. These original community
lessons are not copied course material or an official certification syllabus.
Check current engine/product documentation before adapting examples.
