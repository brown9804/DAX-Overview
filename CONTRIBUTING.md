# Contributing

Welcome focused corrections, original explanations, and reproducible
synthetic examples. Review the existing lessons and companion references first.

- Explain the learning goal and intended calculation object.
- State model names, relationships, storage mode, filters, and expected outputs.
- Distinguish Overview's three-row fixture from the companion retail model.
- Keep the CSV, query body, generated downloads, and directly affected lessons synchronized.
- Record actual DAX engine/client results when available; label unrun exercises honestly.
- Run the [maintenance checks](https://brown9804.github.io/DAX-Overview/maintaining.html).
- Use kebab-case filenames and preserve the existing website format/GPL-3.0 license.

Do not commit production PBIX files, private user mappings, customer records,
credentials, or copyrighted course content. Use original artificial data.
Respect the code of conduct and submit a focused pull request with validation
evidence. A passing Python test does not prove DAX execution or RLS enforcement.
